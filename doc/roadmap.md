# Roadmap / Próximos passos

## 0.1 foundation / Base implementada

- Seven local behaviors / Sete comportamentos locais.
- Immutable 2D state, limits, composition and public API tests.
- Flutter lab, bilingual guides and scientific references.

## Next / Próximas etapas

1. Path following with explicit route ownership and waypoint rules.
2. Static obstacle avoidance with geometry fixtures and visual examples.
3. Separation, alignment and cohesion, then composed flocking.
4. Spatial neighbor lookup and measured multi-agent performance.
5. Optional Flame integration guide and a dedicated example.
6. Publication review, stable version and a separate pub.dev publication.

Estas etapas são planejamento, não funcionalidades já disponíveis. Não há
cronograma ou compatibilidade de API futura garantidos durante a fase inicial.
